# Purpose of AI Use

Our team used ChatGPT as a brainstorming tool during the planning stage of Deliverable 1. AI was used to help identify missing CRUD operations, generate wireframe ideas, suggest screen states, and review whether our project scope was realistic for five students within the project timeline.

# Prompts Used
"Generate CRUD user stories for a Laundry Pickup and Delivery Management System."
"List all screens and UI states needed for Orders, Customers, Pickup, Delivery, and Payments."
"Create low-fidelity wireframes for the Delivery and Payment modules."
"Check if our project scope is realistic for a team of five students."
AI Suggestions

# AI suggested creating complete CRUD screens for every record type and adding screen states such as:

Empty State
Error State
Delete Confirmation
Detail/View Screen
Create Screen
Edit Screen

AI also recommended keeping the system focused on core laundry management features instead of adding advanced features such as GPS tracking, online payment gateways, or AI-powered predictions.

# Final Decisions

Our team accepted the suggestions related to CRUD completeness, wireframes, and screen states because they improved the usability and completeness of the system. We decided not to include advanced features to keep the project achievable within the available time.

# Acknowledgment

AI was used only as a planning and brainstorming assistant. All final decisions, user stories, wireframes, and project scope were reviewed and finalized by the team.
